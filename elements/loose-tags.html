Capturing a list of tags on a form (free-form or from known suggestions).

Do

  • Use to capture a list of free-form or known tags (v-model an array).
  • Pass :counter to scope suggestions; use disabled for read-only display.

Don't

  • Don't rely on placeholder in editable mode (F1) or sm for sizing (F3).
  • Don't assume case is preserved — default mode lowercases (F2).

Decision flow

  1. Just displaying tags (label/count/status)? -> MTag/MStatusTag, not LooseTags.
  2. Read-only display of an existing list? -> disabled.
  3. Pick from a known/suggested set with search? -> asDropdown.
  4. Free-type to create new tags? -> default (editable).
  5. Only one tag allowed? -> singleSelection (with asDropdown).

Usage rules

editable(default)
Use when: user types values + Enter to add; suggestions offered; lowercased/trimmed/deduped
e.g. free-form tags on a monitor
disabled
Use when: show an existing tag list read-only (view-mode forms, detail panels)
asDropdown
Use when: pick from known tags (searchable picker) instead of free-typing
singleSelection
Use when: only one tag may be selected (caps asDropdown to 1)
counter
Use when: scope suggestions to a specific entity (dominant real usage)
editable
Use when: The user should free-type values and press Enter to create tags on a form; existing tags are offered as suggestions. This is the default mode. Values are lowercased, trimmed, and de-duped. v-model is an array of strings.
Don't: Don't use to pick from a fixed known set with search (use asDropdown), to show a list read-only (use disabled), or just to display a single label/count/status (use MTag / MStatusTag).
e.g. Adding free-form tags to a monitor (the Monitor tags input).
