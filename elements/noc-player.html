NOC Player

The NOC / wallboard rotator chrome — a top bar that auto-cycles a set of dashboards on a countdown (logo · prev/title/next · countdown + play/pause + exit) over a body slot for the current dashboard. Self-contained playback: an internal timer advances; ←/→ step, space pauses, Esc exits. Part of the Playback & Timeline family. Watch it count down and rotate.

NOC / wallboard mode — a fullscreen presentation that cycles a set of dashboards on a countdown with prev/next/pause/exit, for a wall display.

Do

  • Use for NOC / wallboard mode — a rotating fullscreen dashboard presentation.
  • Put the actual dashboard (product Widgets grid / charts) in the default slot.
  • Wire `change` to load the next dashboard's data and `close` to exit NOC mode.
  • Use fullscreen="true" for the real wall display (enables the keyboard shortcuts).

Don't

  • Don't use it as the normal app top bar — that's obs-app-header.
  • Don't try to render charts/widgets inside it — that's a data-viz gap; use the slot.
  • Don't hardcode colours — it uses --page-background-color / --border-color / --neutral-* / --primary.

Decision flow

  1. A fullscreen wallboard that rotates DASHBOARDS on a timer (NOC mode)? -> obs-noc-player.
  2. The normal interactive app top bar (search / notifications / user)? -> obs-app-header, NOT this.
  3. Step a time WINDOW under a temporal chart? -> obs-timeline-scrollbar.
  4. Rendering the dashboard itself (widgets grid, charts)? -> put the product Widgets / a chart in the default slot — that is a data-viz gap, not part of this element.
  5. Real wall display vs an inline demo? -> fullscreen="true" for the fixed overlay + keyboard; default is an inline block.

Usage rules

rotating
Use when: a NOC wall display cycling several dashboards on a countdown
Don't: for the normal app chrome (obs-app-header) or a single static dashboard
e.g. dashboards=['Network','Servers','Apps'] interval=30 -> auto-rotates with prev/next/pause
with-logo
Use when: the wall display should carry the tenant/product brand
Don't: an unbranded internal display
e.g. logo="/branding/logo.png"
single
Use when: only one dashboard is pinned — show it with just a title + exit
Don't: when there are several to rotate (pass them all)
e.g. dashboards=['Network Overview'] -> no rotation chrome
empty
Use when: always handle an unconfigured NOC (no dashboards)
Don't: never show a blank body
e.g. dashboards=[] -> 'No dashboards available in this NOC'
fullscreen
Use when: the actual wall display — a fixed full-viewport overlay with keyboard control
Don't: an inline demo/preview (leave fullscreen off so it sits in the page)
e.g. fullscreen -> fixed inset:0 overlay; Esc exits, ←/→ step, space pauses
