Color Picker

A colour picker (color-picker.vue) — a 20×20 swatch preview + chevron trigger opening an MPopover with a colour canvas (vue-color Sketch) + a 16-colour preset palette. Supports `transparent` (a swatch with a red diagonal line). Used for branding, widget, threshold and severity colour selection.

Do

  • Use for free colour choice: brand/theme, widget series, threshold/gauge bands, dashboard background.
  • Offer the 16-colour preset palette for quick on-brand picks; allow a custom hex via the canvas.
  • Support transparent where no-fill is valid (renders a red diagonal swatch).

Don't

  • Do not use for fixed severity/status colours — those come from --severity-* tokens for consistency.
  • Do not use for non-colour values (use a Dropdown/Select/Input).
  • Do not rely on colour alone to convey meaning — pair with a label/icon (a11y).

Decision flow

  1. Picking a COLOUR (branding, widget series, threshold)? -> Color Picker.
  2. A fixed SEVERITY colour? -> use the --severity-* token, not a free picker.
  3. Not a colour (any other value)? -> a Dropdown / Select / Input, not this.

Usage rules

color-picker
Use when: the user picks a COLOUR — a swatch trigger that opens a canvas + the 16-colour preset palette
Don't: for non-colour values (use a Dropdown/Select). For a fixed severity colour, prefer the severity token, not a free picker.
e.g. branding logo/theme colour, widget series colour, threshold/severity colour, dashboard background. Supports transparent.

The trigger is a clickable swatch; the palette cells should have accessible names (the hex/colour name) and keyboard focus. Ensure the current value is announced.
