Menu

The MMenu primitive (a vertical list of selectable icon+label rows, with dividers and danger/positive colours) catalogued in its own right, plus its action-surface usage: the Context/Action menu (FlotoGridActions — a '...' trigger opening an MMenu of actions).

Do

  • Reuse the Menu primitive; use FlotoGridActions for row actions.
  • Colour danger actions with --secondary-red, positive with --secondary-green.
  • Gate menu items by permission (create/edit/delete keys).

Don't

  • Don't confuse an actions menu with a value picker (use Dropdown picker / Select).
  • Don't confuse it with navigation (go somewhere).
  • Don't hand-roll a <ul> dropdown; don't rely on colour alone for danger.

Decision flow

  1. A list of items to render inside something (nav, picker, dropdown)? -> Menu primitive.
  2. A '...' or button that opens a list of ACTIONS on a row/object? -> Context / Action menu.
  3. Pick a VALUE from options (single/multi)? -> Dropdown picker / Select (not this family).
  4. Go to a destination? -> Navigation (Primary nav / Side menu / Tabs).

Usage rules

menu-primitive
Use when: You need a vertical list of selectable icon+label rows rendered INSIDE another surface — a nav, a dropdown picker, a side menu, or a custom overlay. Reach for the MMenu primitive (MMenu / MMenuItem / MMenuDivider) as the shared building block; use MMenuDivider to group rows and the danger (--secondary-red) / positive (--secondary-green) item colours for destructive/affirmative rows. States it carries: hover (--neutral-lighter), selected (--primary on --code-tag-background-color).
Don't: Don't use the bare primitive when you specifically need a '...' trigger opening ACTIONS on a grid row/object — use the Context / Action menu (FlotoGridActions) which adds the ellipsis trigger and permission gating. Don't use it to pick a VALUE (single/multi) — that's Dropdown picker / Select. Don't use it for navigation to a destination — that's Primary nav / Side menu / Tabs. Never hand-roll a <ul> dropdown to replace it.
e.g. The MMenu list that renders the item rows inside the Primary nav, the Side menu, and the Dropdown picker overlays — the same primitive reused across all of them rather than a hand-rolled list.
context-menu
Use when: You need a '⋯' (ellipsis-v) trigger — or a button — that opens a menu of ACTIONS on a specific row/object: Edit, Duplicate, Delete, etc. Use FlotoGridActions (an MPopover placement bottomRight opening an MMenu of action items); pass the row as `resource`, actions as {key,name,icon,isDanger/redAction,greenAction,type:'divider'}, and gate items via create/edit/delete permission keys. Colour destructive actions red (isDanger/redAction) and affirmative ones green (greenAction), each keeping its icon+label so meaning isn't colour-only.
Don't: Don't use it just to render a static list of rows with no action-trigger — use the Menu primitive directly. Don't use it to select a VALUE from options — use Dropdown picker / Select. Don't use it to navigate somewhere — use Navigation. Avoid the 1x MDropdown pattern (rich-text editor table options) as the standard row-action surface; FlotoGridActions is the standard.
e.g. The '⋯' actions menu on each row of a Floto grid (e.g. an alert/monitor/report list), opening Edit / Duplicate / Delete where Delete is red and the whole item set is filtered by the user's create/edit/delete permissions.
