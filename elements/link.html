Anatomy

  • text link (<a>, inherits color)
  • OR button-styled link (MButton)

Anything that navigates the user somewhere (route, URL, anchor).

Do

  • Use for navigation (route/URL): inline links, menus, breadcrumbs, logos.
  • Use as-button for a prominent navigation CTA; pass a Button variant.
  • Name the destination in the link text; add text-primary affordance for inline links.

Don't

  • Don't use a link for an action (save/delete/apply) — use a Button.
  • Don't rely on as-button where open-in-new-tab matters (F1).

Decision flow

  1. Performs an action (save/delete/change state)? -> Button, not a link.
  2. External URL / opens in a new tab? -> plain <a href target=_blank rel=noopener noreferrer> (FlotoLink is internal-only).
  3. Internal navigation (route)? -> FlotoLink.
  4. Internal navigation that should look like a prominent CTA/button? -> FlotoLink as-button (with a variant).
  5. Inline internal navigation in content / menus / breadcrumbs / a clickable value? -> FlotoLink (text link).
  6. A subtle clickable text inside a table/grid? -> class k-link.

Usage rules

text-link(default)
Use when: inline INTERNAL navigation in content, menus, breadcrumbs, logos, a clickable value
Don't: for actions (use Button) or external URLs (use a plain anchor)
e.g. go to <the inventory list>; a breadcrumb segment
as-button
Use when: a prominent INTERNAL navigation call-to-action that should look like a button
Don't: where users expect open-in-new-tab/middle-click (F1 — it's a button, no href)
e.g. Go to settings CTA
external-link
Use when: an external/help/doc URL or anything that opens in a new tab
Must: plain <a href target=_blank> with rel=noopener noreferrer (FlotoLink/RouterLink can't do external; SF-004)
e.g. documentation/help links
k-link(class)
Use when: subtle clickable text inside a table/grid
text-link
Use when: Inline INTERNAL navigation that takes the user somewhere via a route — links inside content/prose, menu items, breadcrumb segments, the app logo, or a clickable value that opens a detail view. First-match default of the FlotoLink decision flow once you've ruled out actions and external URLs. Add class="text-primary" so it reads as a link (bare links inherit text color, F2).
Don't: Not for actions like save/delete/apply/change-state (use MButton) or for external/new-tab URLs (use a plain <a href target=_blank>, FlotoLink is internal-only). Use as-button instead when the internal nav must look like a prominent CTA, or k-link for subtle in-grid text.
e.g. A breadcrumb segment, or 'go to the inventory list' inline in content; the navbar/header/user-menu logo and menu navigation links.
external
Use when: The destination is an external URL or should open in a new tab — documentation, help, or downloadable files. FlotoLink/RouterLink can't resolve external URLs, so hand-author a plain anchor: <a href target="_blank" rel="noopener noreferrer">. The rel is required (SF-004).
Don't: Don't use FlotoLink here (internal-only, can't resolve external URLs). For internal route navigation use text-link or as-button instead. Never omit rel=noopener noreferrer on a target=_blank link (reverse tabnabbing, SF-004).
e.g. A documentation or help link that opens Motadata docs in a new tab.
k-link
Use when: A subtle clickable text inside a table/grid that shouldn't shout — neutral --page-text-color with a hover affordance instead of brand color, so it blends into dense grid rows and pagination. Applied as class="k-link" (25× in the app).
Don't: Don't use for prominent or standalone inline links (use text-link with text-primary), for CTAs (as-button), or for actions (MButton). Not for external URLs.
e.g. A subtle clickable cell value or pagination link inside a data grid.
