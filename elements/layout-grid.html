The default way to lay out form fields and any content needing predictable column proportions — 6 = half a row, 12 = full, with a 16px gutter.

Do

  • Use MRow/MCol for all form field layouts.
  • Sizes: 6 = half, 12 = full, 3 = quarter, 4 = third.
  • gutter 16 for form rows; gutter 0 only for structural wrappers.
  • auto-size for action/compact cells; align inside a cell with flex utilities.

Don't

  • Don't hand-roll a flex grid for form layouts.
  • Don't put a gutter on full-height structural wrappers (use gutter 0).
  • Don't nest deep grids where a single MRow of sized MCols works.

Where it’s used

  • Every form field layout (MRow ~540 files · MCol ~522 files).
  • Cards, summary rows, split panels — anywhere needing column proportions.
  • Default form layout is 6 / 6 (two-up); size 12 for textareas / full-width fields.

Decision flow

  1. Use the 12-col MRow/MCol grid for FORM and content column layout inside a screen region (6 = half, 12 = full, gutter 16).
  2. Laying out the whole SCREEN (header / body / side panel)? -> that's layout-screen-regions, not the form grid.
  3. A dashboard of resizable widget tiles? -> that's the widget GridLayout (a known gap — STOP-and-ASK), NOT this form grid.
  4. One field per row full-width, or two half-width fields side by side -> 12 / 6+6. Action buttons -> auto-size col.
