Data-Viz Tooltips

The product's chart & widget hover tooltips — a distinct family from MTooltip, owned by the chart layer (Highcharts TooltipBuilder, graph canvases, widget Vue components), not DS components. ~28 reference reproductions cover every mechanism.

Kind
Full width (block)
PropTypeDefault
kindstring"bar"
blockbooleanfalse

Tokens used

  • --chart-tooltip-background
  • --topology-graph-tooltip-bg
  • --tooltip-text-color
  • --severity-down
  • --severity-unreachable
  • --severity-critical
  • --severity-major
  • --severity-warning
  • --severity-up
  • --page-text-color
  • --border-color

Do

  • Use the chart layer's TooltipBuilder / widget tooltip; don't build a DS component.
  • Convey severity by token + label, not colour alone.
  • Provide the same data in a table/legend (a11y F2).

Don't

  • Don't reach for MTooltip on a chart mark.
  • Don't rely on hover-only data for accessibility.
  • Don't hardcode tooltip colours — use --chart-tooltip-background / --severity-*.

Decision flow

  1. Hover detail on a CHART/graph/canvas mark? -> data-viz tooltip (owned by the chart layer, not MTooltip).
  2. A UI element/text hint? -> MTooltip (Molecules/Tooltip).
  3. Which one: match the chart/widget type in whichTooltipWhere.

Usage rules

bar-series
Use when: Hovering a mark on a bar/line/area/column chart rendered by the Highcharts TooltipBuilder — metric-trend, top-N, time-series widgets, KPI-trend, or areasplinerange. Shows a title (category/date-time) plus one row per series (8x8 color square, series name, right-aligned unit-applied value); multi-series charts with sharedTooltip show every series at the hovered x with a crosshair.
Don't: When the mark is a slice (use donut-pie), a low-high band (use anomaly-band), or when you need a UI hint on a control rather than a chart mark (use MTooltip). Don't hand-build; content lives in tooltip-builder.js.
e.g. Hovering a column in a metric-trend or Top-N time-series widget on an ObserveOps dashboard to read the per-series value at that timestamp.
donut-pie
Use when: Hovering a slice of an availability/status donut widget or a distribution pie. Highcharts renders it on the hc-tooltip-bg surface; pie omits the header row that bar/line keep.
Don't: For time-series or category columns use bar-series; for hex status grids use heatmap. Not for UI control hints (MTooltip).
e.g. Hovering a segment of a monitor-availability status donut or a severity-distribution pie widget on a dashboard.
bubble
Use when: Hovering a bubble in a packed-bubble widget (category/tag distribution), rendered by bubble-options.vue on hc-tooltip-bg.
Don't: For x/y correlation points use scatter; for hierarchical area use treemap. Not a UI tooltip.
e.g. Hovering a bubble in a category- or tag-distribution packed-bubble widget to read its grouped count.
map-geo
Use when: Hovering a region on a geo-map widget that plots monitor distribution by location (map-chart-options.vue, hc-tooltip-bg).
Don't: For RUM apdex/demographics country markers use geo-marker; for topology nodes use live-graph-node. Not for UI hints.
e.g. Hovering a country/region on a monitor-distribution-by-location geo map widget.
radar
Use when: Hovering a point on a multi-axis radar comparison widget (radar-chart-options.vue, hc-tooltip-bg).
Don't: For single-axis trends use bar-series; for two-variable correlation use scatter.
e.g. Hovering an axis vertex on a multi-metric radar comparison widget to read that axis's value.
timeline-xrange
Use when: Hovering a segment on an SLO timeline or availability timeline (x-range) rendered by timeline-chart-options.vue on hc-tooltip-bg.
Don't: For the colored alert/availability bar segment use availability-segment; for RUM resource timing use rum-waterfall. Not for UI hints.
e.g. Hovering a state band on an SLO / availability timeline widget to read its window.
gauge
Use when: Hovering a solid-gauge, circular-progress, or KPI gauge widget (gauge.vue / circular-progress-options.vue, hc-tooltip-bg).
Don't: For a linear trend use bar-series; for an inline mini-trend use sparkline.
e.g. Hovering the arc of a KPI solid-gauge or circular-progress widget to read the current value.
sankey
Use when: Hovering a node or link on a sankey/flow widget (traffic flow, dependency) rendered by sankey-options.vue on hc-tooltip-bg.
Don't: For topology link details use live-graph-edge or network-interface-edge; for hierarchy area use treemap.
e.g. Hovering a flow band on a traffic-flow or dependency sankey widget.
treemap
Use when: Hovering a tile on a treemap widget (capacity/hierarchy) rendered by tree-map-with-levels.vue on hc-tooltip-bg.
Don't: For packed-bubble distribution use bubble; for a flow diagram use sankey.
e.g. Hovering a rectangle in a capacity/hierarchy treemap widget to read its share.
scatter
Use when: Hovering a point on a scatter widget plotting x vs y per monitor (type:'scatter', hc-tooltip-bg).
Don't: For category distribution use bubble; for multi-axis comparison use radar.
e.g. Hovering a point in an x-vs-y correlation scatter widget to read both coordinates for that monitor.
anomaly-band
Use when: Hovering an anomaly or forecast chart where each point is an actual value vs an expected low-high band (areasplinerange + isAnomalySeries; __getLowHighHtml). Used in anomaly/forecast widgets, metric-explorer, metric-insight; out-of-range points are colored.
Don't: For a plain single-value trend use bar-series (default value format). Anomaly-band is specifically the low-high range value cell.
e.g. Hovering a metric-explorer anomaly chart to compare the actual value against the expected low-high band at that time.
rum-waterfall
Use when: Hovering a resource bar on a RUM session resource-timing waterfall (rum-resource-waterfall.vue, x-range, hc-tooltip-bg) to read start/end/duration.
Don't: For an APM/RUM trace flame graph span use flame-graph-span; for an SLO timeline use timeline-xrange.
e.g. Hovering a resource row in a RUM page resource-timing waterfall to read its start, end, and duration.
geo-marker
Use when: Hovering a country/marker on a RUM apdex-or-demographics-by-country map or a Leaflet online map (apdex-rating-by-country-map.vue / leaflet-map.vue) to read region + severity + metrics.
Don't: For a monitor-distribution geo widget use map-geo; for topology nodes use live-graph-node.
e.g. Hovering a country on the RUM apdex-by-country map to read its region, apdex severity, and metrics.
log-pattern
Use when: Hovering a log pattern count in the log pattern detection grid (log-pattern-detection-grid.vue) — shows a nested VALUE/COUNT/SHARE grid (popover + MGrid, hc-tooltip-bg).
Don't: For a generic chart series row use bar-series. This is the specific log distribution popover.
e.g. Hovering a pattern's count in the Log pattern detection grid to see its value distribution (VALUE/COUNT/SHARE).
sparkline
Use when: Hovering an inline sparkline cell in a grid or metric widget (sparkline-options.vue, hc-tooltip-bg mini) to read the point value on the mini-trend.
Don't: For a full-size trend chart use bar-series; for a gauge use gauge.
e.g. Hovering an inline sparkline cell in a grid row or KPI widget to read the value at that point.
heatmap
Use when: Hovering a cell of a hex heatmap widget — monitor status grid, or SLO/APM/RUM heatmaps (heatmap-tooltip.vue). Surface is --chart-tooltip-background with a severity badge; convey severity by badge + label, not color alone.
Don't: For a segmented availability timeline bar use availability-segment; for a donut use donut-pie.
e.g. Hovering a hex cell in the monitor-status heatmap widget to read the monitor and its severity badge.
availability-segment
Use when: Hovering a segment of an alert/availability timeline bar (segmented-cell-tooltip.vue) — shows start/end/duration + severity on --chart-tooltip-background with a severity badge.
Don't: For the stacked up/down percentage bar use availability-bar; for an SLO x-range timeline use timeline-xrange.
e.g. Hovering a colored segment on an alert/availability timeline bar to read its start, end, duration, and severity.
availability-bar
Use when: Hovering a segment of a stacked up/down percentage bar (availability-bar.vue via MTooltip) — shows 'Status: %' on --tooltip-background-color.
Don't: For a segmented alert timeline with start/end/duration use availability-segment; for a status donut use donut-pie.
e.g. Hovering the up or down portion of a stacked availability % bar to read 'Up: 99.2%'.
live-graph-node
Use when: Hovering a monitor node on a Topology map or Netroute path (topology/netroute node components) — canvas tooltip on --topology-graph-tooltip-bg (fixed-dark in both themes).
Don't: For a link/edge use live-graph-edge or network-interface-edge; for an APM service node use apm-service-node; for a netroute hop use netroute-node.
e.g. Hovering a device node on the Topology map to read the monitor's summary.
live-graph-edge
Use when: Hovering a generic topology/netroute link (edge-tooltip.vue) — shows interface in/out and utilization on --topology-graph-tooltip-bg.
Don't: When the edge is a full network interface link (use network-interface-edge), an SD-WAN tunnel (sdn-tunnel-edge), an ACI link (cisco-aci-link), or a netroute transit edge (netroute-edge).
e.g. Hovering a link on the topology map to read its in/out interface utilization.
apm-service-node
Use when: Hovering a node on the APM service map (servicemap-tooltip.vue) — throughput/latency/error on --topology-graph-tooltip-bg.
Don't: For a generic topology monitor node use live-graph-node; for a flame graph span use flame-graph-span.
e.g. Hovering a service node on the APM service map to read its throughput, latency, and error rate.
sdn-tunnel-edge
Use when: Hovering an SD-WAN tunnel edge (sdn-tunnel-edge-tooltip.vue) — latency/loss/jitter KPIs plus health/color/site on --topology-graph-tooltip-bg.
Don't: For a plain interface edge use network-interface-edge; for an ACI fabric link use cisco-aci-link.
e.g. Hovering an SD-WAN tunnel on the SDN topology to read its latency, loss, jitter, and health.
cisco-aci-endpoint
Use when: Hovering a Cisco ACI leaf-to-endpoint edge (cisco-aci-edge-tooltip.vue) — MAC/IPv4/IPv6/endpoint-group on --topology-graph-tooltip-bg.
Don't: For an ACI leaf-to-leaf fabric link use cisco-aci-link; for a generic interface edge use network-interface-edge.
e.g. Hovering a leaf-to-endpoint connection on a Cisco ACI map to read the endpoint's MAC, IPv4/IPv6, and group.
cisco-aci-link
Use when: Hovering a Cisco ACI leaf-to-leaf fabric link (cisco-aci-link-edge-tooltip.vue) — node/pod/role/state/interface on --topology-graph-tooltip-bg.
Don't: For a leaf-to-endpoint edge use cisco-aci-endpoint; for a non-ACI interface link use network-interface-edge.
e.g. Hovering a fabric link between two ACI leaves to read node, pod, role, state, and interface.
network-interface-edge
Use when: Hovering a network link on a topology map (network-interface-edge-tooltip.vue) — both-sides interface details: alias/status/IP/speed/traffic on --topology-graph-tooltip-bg.
Don't: For a generic edge with just in/out utilization use live-graph-edge; for SD-WAN tunnels use sdn-tunnel-edge; for ACI use cisco-aci-link.
e.g. Hovering a network link on the topology map to read both interfaces' alias, status, IP, speed, and traffic.
netroute-node
Use when: Hovering a hop node on a Netroute path (netroute/node-tooltip.vue) — latency min/avg/max + loss + alerts on --topology-graph-tooltip-bg.
Don't: For a netroute transit edge use netroute-edge; for a topology monitor node use live-graph-node.
e.g. Hovering a hop in a Netroute path to read its latency min/avg/max, loss, and alerts.
netroute-edge
Use when: Hovering a transit edge between hops on a Netroute path (netroute/edge-tooltip.vue) — latency/loss plus transit likelihood on --topology-graph-tooltip-bg.
Don't: For a hop node use netroute-node; for a generic topology edge use live-graph-edge.
e.g. Hovering the transit segment between two Netroute hops to read latency, loss, and transit likelihood.
flame-graph-span
Use when: Hovering a span in a d3 flame graph (d3-flame-graph.vue) — APM trace drill-down or RUM view/action/long-task flame graphs. Shows name + self/total + % of trace; long-task adds source URL + invoker. Surface hc-tooltip-bg.
Don't: For a RUM resource-timing waterfall use rum-waterfall; for an APM service-map node use apm-service-node.
e.g. Hovering a span in an APM trace flame graph to read its name, self/total time, and % of the trace.
