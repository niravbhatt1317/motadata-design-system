Choosing exactly one option from a small, visible set.

Do

  • Use MRadioGroup with :options for one-of-many; v-model the value.
  • Use as-button for a small set of always-visible exclusive choices.
  • Disable individual options with option.disabled.

Don't

  • Don't use radio for multi-select (Checkbox) or instant on/off (Switch).
  • Don't use radio for many options / tight space (DropdownPicker).
  • Don't render standalone MRadio — go through the group.

Decision flow

  1. Multi-select (pick any number)? -> Checkbox.
  2. Instant on/off? -> Switch.
  3. Many options or space-tight? -> DropdownPicker.
  4. Pick exactly one from a few visible options? -> Radio.
  5. [Radio style] >6 options? -> DropdownPicker instead.
  6. [Radio style] Longer labels / vertical form field? -> radio list (default).
  7. [Radio style] Alert severity filter (Critical/Major/Warning)? -> Severity switch (radio-toggle-shadow + alert-severity-buttons, as-button).
  8. [Radio style] Each option clearer with an icon (view/mode toggle)? -> Segmented with icons (as-button + icon in option slot).
  9. [Radio style] Otherwise small compact set (2-5)? -> plain segmented (as-button).

Usage rules

radio-list(default)
Use when: pick one of a few options with a vertical/inline list; longer labels OK
e.g. severity Low/Medium/High on a form
segmented(as-button)
Use when: a small set (2-5) of always-visible, mutually-exclusive choices; compact
e.g. time range 1h/24h/7d/30d, view-mode toggle
segmented+icons
Use when: segmented where each option reads better with an icon (icon via option slot; without-icon-margin context, 14x)
e.g. grid/list/map view toggle
severity-switch
Use when: borderless segmented with separators (real combo: radio-toggle-shadow + alert-severity-buttons, as-button)
e.g. severity-switch.vue (Critical/Major/Warning)
disabled
Use when: whole group not changeable; or option.disabled for one option
size=small
Use when: dense toolbars (segmented)
list
Use when: Pick exactly one from a few options where labels may be longer, inside a form or settings panel — the default radio style, laid out vertically or inline. Used for form fields and mode choosers with descriptions.
Don't: Don't use for a compact side-by-side toggle (use segmented), for multi-select (Checkbox), instant on/off (Switch), or more than ~6 options / tight space / needs search (DropdownPicker).
e.g. Severity Low / Medium / High on a form; a mode chooser with per-option descriptions.
segmented
Use when: A small set (2-5) of always-visible, mutually-exclusive choices that benefit from being compact and side-by-side — rendered as joined buttons via as-button (255x). This is also the Button family's segmented control.
Don't: Don't use for long labels or vertical form fields (use list), when each option needs an icon to be clear (use segmented-with-icons), for the alert-severity look (use severity-switch), or for >6 options (DropdownPicker).
e.g. Time range 1h / 24h / 7d / 30d and chart view toggles in the metric explorer toolbars and anomaly/forecast/outlier modals.
segmented-with-icons
Use when: A segmented control where each segment reads better with an icon — view/mode toggles. Put the icon in the option slot (as-button + icon; without-icon-margin context, 14x).
Don't: Don't use when text labels alone are clear (plain segmented), for form fields with long labels (list), or for the borderless separator alert-severity look (severity-switch).
e.g. Grid / list / map view toggle.
