Grid Select

The grid / table dropdown (obs-grid-select) — a dropdown whose menu is a searchable TABLE, not an option list: columns · per-row checkboxes · sortable header · a search box · a selected-count badge + View Selected / Clear Selected. Rich cells via a column `type` (text · status · severity · type-icons). The product's 'Select Agent / Select Monitor' picker (FlotoDropdownGridSelector + MonitorPicker/AgentPicker, ~70×). The open table floors at 720px wide so the View Selected / Clear Selected actions sit on one line and more columns are visible.

Do

  • Use for agent / monitor / device / interface / user / profile selection — records needing columns to tell apart.
  • Give a column a `type` (any obs-table cell type — severity/dot/status/type/tags/sparkline/heat/bar) for the DS severity dot (obs-severity), status tag (obs-tag), product type icons, etc.
  • Use multiple for bulk selection (checkboxes + Select-All + the selected badge + View/Clear Selected).

Don't

  • Don't use for a short fixed {label} option list (use the plain Dropdown/Select).
  • Don't use for a menu of commands/actions (use a Menu).

Decision flow

  1. Picking a rich RECORD that needs multiple columns to identify (name · IP · type · status), often multi-select? -> Grid Select.
  2. Picking a simple {label} value from a list? -> the Dropdown picker / Select, not this.
  3. A menu of ACTIONS (Edit/Delete)? -> a Menu, not this.

Usage rules

grid-select
Use when: the user picks a rich RECORD identified by multiple columns (name/IP/type/status), often multi-select with checkboxes — the menu is a searchable table, not a plain list.
Don't: for simple {label} options (Dropdown/Select) or a menu of actions (Menu).
e.g. Select Agent / Select Monitor pickers (~70×): agent, monitor, device, interface, RUM service, integration/SNMP-trap profile, user selection.

The trigger is a button with the selection/placeholder. The open menu is a table; give sortable headers aria-sort, selectable rows aria-selected, the header checkbox = select-all, arrow-key row nav, and announce the result/selected count. The menu renders in the top layer (Popover API).
