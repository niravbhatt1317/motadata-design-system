Any user-triggered action (submit, create, delete, apply).

Do

  • Use variant=primary for the single main action on a view.
  • Use danger/error for destructive actions, paired with a confirm.
  • Use neutral-* variants for secondary/tertiary actions.
  • Show :loading during async work to prevent double-submits.

Don't

  • More than one primary button in the same action group.
  • Hardcoding colors — variants already map to design tokens.
  • Using a button for what is really a link (use FlotoLink).

Decision flow

  1. Navigates (route/URL/anchor)? -> link (FlotoLink), not a button.
  2. Destructive (delete/remove/abort)? -> variant=error + confirm.
  3. Single most-important action on the view/dialog? -> variant=primary (primary-alt for confirm inside a modal).
  4. Cancel/Reset/secondary next to the primary? -> variant=default.
  5. Quiet utility in toolbar/list/grid/filter? -> variant=neutral-lightest.
  6. Inline text-like action (Add/Create New/Clear All)? -> variant=transparent.
  7. Icon-only / space-tight? -> icon button (class=squared-button, or shape=circle).
  8. Modifiers: block=full width; outline=ghost/bordered; size=small for dense. Avoid neutral/info (navy, F1).

Usage rules

primary
Use when: the ONE most-important action on a view/form/wizard
Don't: if a primary already exists, or action is destructive/navigation
e.g. Apply (filter), Save (form), Verify Password (login)
primary-alt
Use when: the confirm/save inside a modal where full navy is too heavy
Don't: for the page-level main action (use primary)
e.g. Save/Confirm/Restore in dialogs
default
Use when: the secondary next to a primary: Cancel/Reset/Clear/Back
Don't: for the main action or destructive action
e.g. Cancel beside Save; Reset on a filter
neutral-lightest
Use when: quiet utility controls in toolbar/list/grid/filter
Don't: for the main or inline-text action
e.g. Filter bar, Hide all, granularity toggles
neutral-lighter
Use when: subtle add/secondary slightly stronger than transparent (rare)
Don't: when unsure (prefer transparent or default)
e.g. Add New Controls, Export
transparent
Use when: inline text-like actions: Create New/+Add/Clear All/in-content
Don't: for navigation (use FlotoLink) or when more prominence is needed
e.g. Create New, Add Credential, Clear All
error
Use when: destructive: delete/remove/abort/discard, with a confirm
Don't: for normal saves
e.g. Delete Selected, Abort
success
Use when: explicit approve/accept in a review flow (rare)
Don't: for a generic save (use primary)
e.g. Approve (sync-approval drawer)
outline
Use when: secondary needing a clear edge, e.g. on busy/colored/image backgrounds
Don't: when default/transparent reads clearly on a plain surface
e.g. bordered action on a colored panel
squared-button
Use when: recognizable repeated space-tight icon action (row edit/delete, toolbar, modal close); 35x35
Don't: when the icon meaning isn't obvious
Must: aria-label
e.g. row delete, toolbar tools
shape=circle
Use when: standalone/floating icon action (overlays)
Must: aria-label; add :rounded=false for a true circle (F7)
e.g. topology/chart overlay controls
block
Use when: button should fill its container: drawers, mobile, single-action forms, login
Don't: in a row with other buttons
link(FlotoLink)
Use when: the control navigates (route/URL/anchor)
Don't: for actions that change data/state (use a button)
danger
Use when: Avoid in new work — it is a rare (3×) light/ghost style, NOT solid red (finding F2). For anything destructive prefer error + a confirm.
Don't: For real destructive actions (use error) or for a normal save (use primary); the ghost rendering under-signals danger.
e.g. Legacy light ghost-danger action; migrate to error for delete/remove flows.
icon-circle
Use when: An icon-only action where a circular/standalone/floating affordance is wanted — overlay and floating controls (topology/chart overlays). Must provide an aria-label.
Don't: For a repeated in-table/toolbar icon action (use squared-button) or when the icon's meaning isn't obvious (use a labelled button). Note: renders as a 4px rounded square unless you add :rounded=false (finding F7).
e.g. Topology / chart overlay controls (button-topology-overlay); floating map controls.
