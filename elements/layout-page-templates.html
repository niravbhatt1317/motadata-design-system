The seven canonical page templates

List view — header · toolbar · table · pagination
Form view — back · title · actions, then a field grid
Detail view — header + status · tabs · panels
Dashboard view — picker · time range · widget grid
Explorer view — left tree/filter · query bar · results
Wizard flow — stepper · step body · Back/Next
Graph / Canvas — tree · interactive node graph · minimap

Page templates

The canonical page types ObserveOps repeats, as annotated wireframes inside the app frame — built from the composition recipes. List view (header + toolbar + table + pager) · Form view (field grid) · Detail view (header + tabs + panels) · Dashboard view (picker + time range + widget grid) · Explorer view (left tree/filter + query + results) · Wizard flow (stepper + step + Back/Next) · Graph / Canvas (tree + interactive node graph).

Pick the page archetype that matches the task, then assemble it from the per-region components (recipes).

Do

  • Assemble pages from these archetypes + the per-region component mapping (recipes.json).
  • Use the List view for the most common index pages; Form/Detail for records.
  • Graph/Canvas (topology) is its own archetype — not a Dashboard or Explorer.

Don't

  • Don't invent a new page shape where one of these seven fits.
  • Don't put a second scrolling region inside the body.

Where it’s used

  • List view — inventory / alert / policy lists.
  • Form view — monitor / policy / credential forms · Detail view — monitor / alert detail.
  • Dashboard view — dashboards / NOC · Explorer view — log / metric explorers.
  • Wizard flow — discovery / report setup / 2FA · Graph / Canvas — topology.

Decision flow

  1. Browsing/managing MANY records (a list you filter, sort, page)? -> List view (list-view recipe).
  2. Create or edit ONE record? -> Form view (form-view) — off a list use a Drawer; complex/settings forms use a full page.
  3. Viewing ONE record's details (status + related tabs)? -> Detail view (detail-view).
  4. Metrics / an at-a-glance overview? -> Dashboard (dashboard-view, tiles).
  5. Querying/exploring a dataset (filters + results, e.g. logs)? -> Explorer (explorer-view).
  6. A guided, multi-step task? -> Wizard (wizard-flow).
  7. Pick the archetype by what the page is FOR; don't invent a new page shape where one of these seven fits.
