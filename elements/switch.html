Immediate on/off settings (enable feature, toggle status).

Do

  • Use for immediate on/off settings; show :loading while persisting.
  • Control via v-model / :checked.

Don't

  • Using a switch in a form that needs explicit Save (use MCheckbox).
  • Relying on :defaultChecked (no-op, F1).

Decision flow

  1. Mutually-exclusive options? -> MRadio.
  2. Applies immediately (no Save)? -> Switch.
  3. Committed only on form Save (opt-in/consent/multi-select)? -> MCheckbox.

Usage rules

switch
Use when: single binary setting that applies the moment you toggle it
Don't: if saved with a form (use checkbox) or one-of-many (use radio)
e.g. Enable notifications; monitor on/off
loading
Use when: the toggle triggers an async persist; block re-toggle until resolved
disabled
Use when: setting exists but can't change in current state/permission
size=small
Use when: dense rows/tables

Known a11y issues

  • No visible focus ring.
  • aria-checked missing in the OFF state.
  • On/off signalled mainly by knob colour — add a non-colour cue.
