# Button — Changelog

- **2026-06-16** — Added an **Interaction states** story (hover / active / focus / disabled on the real
  `MButton`) that **surfaces SF-001** — the system-wide removal of the `:focus-visible` ring, so
  keyboard focus is not visibly indicated. (From the catalogue audit: states were documented but never
  shown.)
- **2026-06-05** — Added to Storybook. Variants corrected to the distinctly-rendering set;
  `primary-alt` added; `info`/`neutral`/etc. moved to a flagged "navy fallback" story.
- **2026-06-05** — Light/dark verified (primary flips white-on-navy in dark).
- **2026-06-06** — Enhanced doc standard: Anatomy, Behaviors, Content, Accessibility
  (focus-ring + target-size findings), Related, Changelog.
- **2026-06-06** — Split into Storybook sub-pages: Usage · Accessibility · Changelog.
- **2026-06-07** — Thorough whole-product button audit. Added an **Icon buttons** story
  (`shape="circle"` 218× + `.squared-button` 365×) and an **Outline / ghost** story; added
  icon/shape/squared controls to the **Playground**. New findings **F6** (the `shadow` prop is
  inverted) and **F7** (`shape="circle"` renders as a rounded square, not a circle — ~174 of
  198 uses). Noted button-like relatives `FlotoLink` (67×) and the segmented control
  (`MRadioGroup as-button`, 255×).
