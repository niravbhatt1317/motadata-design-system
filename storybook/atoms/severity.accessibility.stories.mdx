# Severity — Accessibility

## Verify

- ⚠️ **Not colour-only (F2)** — the default is a bare coloured dot. Severity must not be conveyed by
  colour alone (WCAG 1.4.1): set **`displayText`** to show the label, or keep the **tooltip** (the
  component wraps an `MTooltip` with the capitalized level), so the level is available as text.
- ⚠️ **Tooltip text** — when `disableTooltip` is set, ensure the level is still exposed (label or a
  `title`/`aria-label`).
- ⚠️ **Contrast** — the dot (`--severity-<level>`) on its halo (`--severity-<level>-dot-box`) and the
  label text must meet contrast in **both** themes.
- ⚠️ **Live updates** — when severity resolves/changes live, announce meaningfully (avoid silent colour
  swaps for assistive tech).
