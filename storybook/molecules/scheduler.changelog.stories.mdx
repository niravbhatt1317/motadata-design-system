# Scheduler / Recurrence — Changelog

- **2026-06-16 (sweep recheck — no variants missed)** — Census of every `<ScheduleInput>` (16×):
  **types are Once/Daily/Weekly/Monthly only** (the `'Hourly'` found elsewhere is a *granularity*
  dropdown in policy anomaly/forecast conditions, not a recurrence type). Added the missed **`:disabled`**

  Start Date + Hours · **Weekly** → Days (Mon–Sun) + Start Date + Hours · **Monthly** → Months + Dates
