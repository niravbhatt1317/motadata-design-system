# Color Picker — Changelog

- **2026-07-11** — Added — the **Color Picker** (`color-picker.vue`). A **20×20 swatch preview + chevron**
  trigger opening an `MPopover` with a color canvas (`vue-color` Sketch) and the product's **16-color preset
  palette**. Supports **`transparent`** (a swatch with a red diagonal line). Catalogued in the **Form Controls**
  family (next to Select / Dropdown / Input), with a decision flow (severity color → token, not a free picker),
  do/don't, `usageRules`, and the accessibility rules (label the trigger + palette cells; don't convey meaning
  by color alone). Found in the Group-C sweep of the dropdown/menu family.
