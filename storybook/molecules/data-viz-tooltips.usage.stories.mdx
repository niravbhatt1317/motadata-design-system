# Data-Viz Tooltips — Usage

The **chart & widget hover tooltips** — a family distinct from the UI `MTooltip`. They are
rendered by the **charting layer** (Highcharts), **widget components**, or the **graph canvas**
(topology / flame graph), not by a DS Vue component — so the catalog shows them as **reference
reproductions** (real tokens).

## 🔎 Which tooltip → where it's used (lookup)

Find the **chart / graph / place** you're working on, read across for the **tooltip** it uses, its
**renderer**, and the **surface token**. (This is the AI/designer lookup — "on *this*, use *that*.")

## The renderers (3)

- **Highcharts** — one shared **`TooltipBuilder`** (`src/components/chart/options/tooltip-builder.js`)
  + per-chart-type formatters, all on the **`hc-tooltip-bg`** surface (`--chart-tooltip-background`
  + `blur(15px)`). Covers every chart-type row above.
- **Widget components** — `heatmap-tooltip.vue` (and similar) render their own Vue tooltip content.
- **Graph canvas** — **topology / netroute / APM service-map** (15 node/edge components) and the
  **d3 flame graph** draw tooltips directly on the canvas; surface `--topology-graph-tooltip-bg`
  (graph) / `hc-tooltip-bg` (flame).

## Chart tooltip structure (the shared row format)

`TooltipBuilder` builds: a **title** (category / date-time) + one **row per series** — an **8×8
color square** (series color) · the series name · the right-aligned **value** (unit-applied). Pie
omits the header; bar/line keep it.

**Value-format variants** (same row, different value cell — `tooltip-builder.js`):

- **default** — a single value (`__getDefaultValueHtml`) — the **Chart — bar** story.
- **low–high range** — anomaly / forecast band (`__getLowHighHtml`) — the **Anomaly band** story.
- **from–to range** — histogram / range bins (`__getRangeHtml`, e.g. `40 – 60 : 12`).
- **duration** — `value (duration)` (`__getDurationHtml`) — trace / timeline spans.

**Shared / crosshair tooltip** — multi-series charts with `sharedTooltip: true` (`shared: true`)
show **one tooltip listing every series** at the hovered x, with a vertical crosshair (e.g. a
multi-metric trend, RUM demographics). The **Chart — bar** story already shows this multi-row
form; single-series charts collapse it to one row.

## Do / Don't

- **Do** keep these consistent with the renderer's surface (`--chart-tooltip-background` /
  `--topology-graph-tooltip-bg`) and the series/severity colors — changes belong in
  `tooltip-builder.js` / the chart & graph LESS, not per-widget.
- **Don't** confuse them with **`MTooltip`** — these are **not** the DS UI tooltip. For a UI hint
  use `MTooltip`; for a truncation hint use native `title=`.
